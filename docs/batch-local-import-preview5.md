# preview.5 批量 Markdown 与本地路径导入

## 使用

纯浏览器扩展，无本机 CLI。打开插件“导入”，支持多选 Markdown/HTML，或选择含文档和配套图片的目录。每份文档独立上传，不合并正文。

通过路径添加时：

1. 展开“通过本地路径添加”，点击“授权文件夹”，选择例如 `C:\笔记`。选择窗口也可粘贴路径。
2. 使用完整路径时，在“授权目录完整路径”填写 `C:\笔记`；浏览器不提供目录的完整磁盘路径，此值只是对已选择目录的路径映射。
3. 每行输入一个文件或目录，可混用 `C:\笔记\文章\第一篇.md`、`文章\第二篇.md`、`学习笔记`。留空添加整个目录。
4. 点击“按路径添加”，检查列表。目录递归匹配，重叠路径去重，错误路径单独报告。所有匹配仍限于已授权目录。
5. 点击各项“预览”可检查正文和修改标题。勾选文档和已登录的平台，点击“批量同步 N 份文档”。

Chrome 的目录授权能力见 [File System Access 官方文档](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access)。输入路径本身不会授予磁盘读取权限；Chrome 不支持该目录 API 时使用原生文件夹选择作为兼容入口。

## 结果与资源边界

- 每次最多 100 份文档、200 行路径。目录扫描最多 5000 条目、32 层、50 MiB 支持文件；单篇和图片继续采用既有大小限制。
- 页面持有只读文件引用，准备和发送一次仅处理一份正文。飞书同步依次占用和恢复剪贴板，复用已有服务端保存校验。
- 缺图或准备失败只阻止该项，明确的同步失败记录后处理下一项。成功的平台跳过；飞书已创建但失败的项禁止直接创建另一份。
- 后台结果不明确时停止整个批次，避免仍在运行的后台任务与下一份争用剪贴板；需先检查文档和同步历史。
- 停止按钮等待当前上传返回后停止。关闭导入页不会取消已发送的后台任务，后续文档不再启动。
- 仅持久保存路径、标题、状态和结果链接等摘要；不保存源文件正文、文件对象或目录授权，不自动恢复上传。清空列表不删除已上传文档。
- 文件未读取到或被修改时以准备结果为准。已授权目录的扫描快照不会自动刷新，新增/修改文件后重新授权或重新选择。

## 回滚

停用扩展，将 preview.4 包内容解压回同一固定安装目录，重新加载并打开导入页。不要删除原目录或改用另一个路径，以免更换扩展 ID 和 OneNote 重定向地址。旧结果摘要无需删除，源文件保持原样。
